# ☕ Starbucks Landing Page

A stylish Starbucks-inspired landing page. Click the drink thumbnails to change the featured drink — the background circle changes color to match.

## ✨ Features

- Hero section with headline and call-to-action
- **Thumbnail image slider** that swaps the main drink image
- **Dynamic background color** that matches the selected drink
- Navigation bar and social media icons

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📁 Project Structure

```
8 starbucks/
├── index.html      # Markup + inline slider script
├── style.css
├── script.js
└── image/          # Drinks, thumbnails, logo and social icons
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vyom1912/<repository-name>.git
   ```
2. Open `index.html` in your browser — no build step or installation needed.
